# Portfolio

This repository contains a professional portfolio built with React, Vite and Tailwind CSS.

Assets included:
- profilePic.png (profile image)
- Mayur_Chablani_Resume_15_SEPT_2025.pdf (resume)

Quick start:
1. npm install
2. npm run dev

Build:
- npm run build
- npm run preview
